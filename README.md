# DroneTV – UI/UX Designer & Frontend Developer Internship Practical Test

## Project Description

DroneTV is a modern, responsive web interface designed for a drone-learning platform.

The project includes a clean and user-friendly interface for users to:

- Sign in to the platform
- View the dashboard
- Browse available courses
- View course information
- Navigate between different sections
- Access progress and certificate sections
- Interact with buttons, navigation menus, and forms

The design focuses on simplicity, usability, responsiveness, and a modern dark-themed UI.

This project was developed as part of the **UI/UX Designer & Frontend Developer Internship – Practical Test Assignment** for **IPAGE Group**.
